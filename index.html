회사 소개

복잡한 데이터를 사람이 쉽게 쓰는 도구로 바꾸는 일을 합니다.

이퀴비젼에이아이 주식회사는 인공지능 모델을 연구하는 데서 끝나지 않고, 그 모델이 서버와 화면에서 안정적으로 돌아가는 소프트웨어까지 이어서 만듭니다.

데이터를 모으고 정리하는 일부터 모델 학습, 결과를 보여 주는 화면과 서버까지 이어서 개발합니다.

기술 일부는 특허 출원 중입니다.

기술 역량

다섯 가지 분야를 하나로 이어서 개발합니다.

머신러닝

표 형태 데이터에서 규칙과 패턴을 찾아 예측·분류 모델로 만듭니다. 모델이 믿을 만한지 검증하는 과정까지 포함합니다.

딥러닝

여러 층으로 이루어진 신경망으로 이미지·영상·시계열처럼 복잡한 데이터에서 특징을 스스로 학습하게 합니다.

컴퓨터 비전

사진과 영상 속 대상을 찾아 따라가고, 관절·움직임 같은 값을 숫자로 뽑아냅니다.

데이터 파이프라인

흩어진 자료를 자동으로 모으고 정리해 모델과 화면으로 흘려보내는 길을 만듭니다. 실패하면 알려 주고, 같은 일을 반복해도 결과가 같게 설계합니다.

소프트웨어 개발

웹·서버·자동화 프로그램을 개발하고 운영합니다. 모바일에서도 읽기 쉬운 화면을 기본으로 합니다.

데이터가 소프트웨어가 되기까지

자료 수집에서 서비스 운영까지 하나의 흐름으로 만듭니다.

수집·정리흩어진 자료를 모아 쓸 수 있게 다듬습니다
모델 학습머신러닝·딥러닝으로 패턴을 익힙니다
검증결과를 다시 확인하고 기록합니다
서비스 운영서버와 화면으로 실제 사용하게 합니다

개발 방식과 강점

작게 만들고, 확인하고, 넓혀 갑니다.

  1. 문제부터 정리합니다무엇을 알고 싶은지, 데이터가 충분한지부터 함께 확인합니다.
  2. 작게 만들어 먼저 검증합니다작은 시제품으로 가능성을 확인한 뒤 범위를 넓힙니다. 검증하지 못한 결과는 결과라고 말하지 않습니다.
  3. 모델에서 서비스까지 이어서 만듭니다학습한 모델이 서버와 화면에서 실제로 쓰이도록 이어서 개발합니다.
  4. 기록하고 다시 점검합니다데이터와 모델의 변화를 기록하고, 주기적으로 다시 확인해 문제를 일찍 찾습니다.
  5. 보안과 개인정보를 기본으로 둡니다꼭 필요한 정보만 다루고, 비밀 정보는 코드와 문서에 남기지 않습니다.
